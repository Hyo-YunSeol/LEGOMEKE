# 레고 키우기 v6.4.0

Cloudflare Workers + Durable Objects(SQLite) 기반 레고방 소셜 다마고치 웹게임 최종 프로젝트입니다.

기존 포인트 생활, 레고력/레벨, 벙, 개인게임, 낚시, 라이어게임, 4×4 영토전, 매칭/커플/찌르기/교미, 10단계 체형 도감, 상태메시지, 레고 파손/세대교체, 운영자 관리 기능을 유지하면서 v6.4.0에서 아래 기능을 추가했습니다.

- 개인게임 전체 합산 게임 하루 30회
- 사과게임: 10×10, 1~9 숫자, 2분, PC/모바일 드래그, 합 10 제거, 서버 권위형 포인트 정산, 한 판 최고점 TOP 5
- 낚시 게임 하루 20회
- 오목게임: 별도 로비, 최대 3방, 15×15 1:1, 관전, 판돈, 흑/백 랜덤, 흑 33·44·장목 금수, 서버 30초 턴, 3연속 시간초과 기권패, 재대결, 승/무/패 TOP 5
- 라이어게임 관전: 플레이어와 관전자 분리, 모든 입력 서버 차단, 게임 종료 전 제시어·라이어 등 비밀정보 미전송
- 회원가입 본인 닉네임 안내문

사과게임 랭킹용 게임 점수는 포인트와 분리해 **제거한 숫자 1개당 20점**으로 계산합니다. 포인트는 요구 규칙대로 성공 1회 +2P, 한 번에 3개 이상 제거 시 추가 +1P입니다.

배포 전 `npm run verify`, 배포는 `npm run deploy:cloudflare`를 사용합니다. 기존 게임 업데이트 시 `wrangler.jsonc`의 Worker 이름과 Durable Object 마이그레이션을 임의로 바꾸지 마세요.

자세한 신규 구현은 `FINAL_REQUIREMENTS_V640_KO.md`, 검증 결과는 `FINAL_VERIFICATION_V640_KO.md`를 확인하세요.
