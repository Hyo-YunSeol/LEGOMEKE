레고 키우기 v6.4.2 최종 프로젝트

1. Node.js 22 이상을 사용합니다.
2. 기존 Cloudflare 게임을 업데이트할 경우 wrangler.jsonc의 Worker name `lego`와 Durable Object 구성을 그대로 유지합니다.
3. npm install
4. npm run verify
5. npm run deploy:cloudflare
6. 배포 후 /healthz에서 6.4.2-final을 확인합니다.

v6.4.0 핵심 기능:
- 개인게임 전체 합산 게임 하루 30회
- 사과게임 10×10 / 2분 / 서버 검증 정산 / 최고점 TOP 5
- 낚시 게임 하루 20회
- 오목 15×15 실시간 1:1 / 최대 3방 / 관전 / 판돈 / 30초 턴 / 금수 / 재대결 / TOP 5
- 라이어게임 읽기 전용 관전 및 게임 종료 전 비밀정보 서버 차단
- 회원가입 본인 닉네임 안내문

v6.4.1 추가 수정:
- 내 레고 게임 순위에 홀짝 / 사과게임 / 오목 TOP 5 통합
- 게임 화면: 포인트 개인게임 → 단체게임 → 오목게임 → 라이어게임
- 현재 시즌 황금 영토는 종료 전 서버에서도 완전 비공개
- 운영자 회원 포인트 지급/회수

v6.4.2 최종 수정:
- 오목판 15열·15행 + 보드 1:1 + 셀 가로/세로 100% 고정으로 정사각형 왜곡 수정
- 운영자 회원 계정 완전 삭제 기능 추가
- 운영자 본인 삭제 차단, 일반 사용자 호출 차단
- 삭제 회원의 현재/과거 세대 및 연결 상태 정리
- 삭제 회원의 기존 로그인 토큰 즉시 무효
- 진행 중 오목 삭제는 기권 정산, 진행 중 라이어 삭제는 안전 종료/환불

중요: 자동 문법검사와 서버/API/UI 정적 테스트는 수행합니다. 실제 Cloudflare 운영 배포 후에는 사용하는 휴대폰 브라우저에서 오목판이 실제 화면에서도 1:1로 보이는지 마지막으로 한 번 확인하세요.
